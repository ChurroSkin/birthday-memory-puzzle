# birthday-memory-puzzle

I built this for my best friend's birthday. It’s a riddle locked puzzle game that turns our shared history into a series of challenges.

## How it works:
* **The Gatekeeper:** You need the right answer to get in. If you're wrong, the UI shakes.
* **The Puzzles:** 14 photos split into 5 distinct puzzle stages. You have to clear each stage to move on.
* **The Vibe:** Dark, midnight themed, and responsive.

## How to use:
Just drop your 14 photos into the folder (named `picture1.jpeg` through `picture14.jpeg`) and set your custom password in `script.js`.
